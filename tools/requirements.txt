# WIST-4 §4's VRF (ECVRF-EDWARDS25519-SHA512-TAI, RFC 9381) adds no dependency
# on purpose: `cryptography` exposes no edwards25519 group operations, and
# every third-party ECVRF package would be an unaudited trust root for the
# rule that decides who audits whom. tools/ecvrf.py implements it in pure
# Python from the RFC text and re-proves itself against RFC 9381 Appendix
# B.3 on every harness run (tools/validate_examples.py, check
# `ecvrf:rfc9381-b3-vectors`).
